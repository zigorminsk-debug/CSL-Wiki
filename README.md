# CSL Wiki Native — Confluence для Android

Нативный клиент для **https://w.csl.by**, без встроенного браузера. Android Java,
Confluence REST API, Android widgets, SQLite. В этой версии только Confluence,
не Jira; операции чтения, поиска и офлайн-сохранения. Редактирование не добавлено.

## Что изменилось в 0.2

- **Нативная форма логина и пароля**, а не сайт Confluence внутри окна.
- Одна кнопка **«Войти»**. Проверка сессии и переход к пространствам автоматические.
- **Нативный читатель статей**: Android TextView, таблицы с горизонтальной прокруткой,
  код, списки, заголовки и ImageView. В production-коде нет WebView.
- Кнопка оригинала открывает внешний браузер только по явному желанию пользователя;
  сайт больше не используется как основной интерфейс приложения.
- Сессионные cookies сохраняются зашифрованными AES-GCM с ключом Android Keystore.
  Пароль не сохраняется ни в SharedPreferences, ни в SQLite, ни в файлах.

## Авторизация

Приложение делает HTTPS GET `/login.action`, извлекает стандартную форму
Confluence Server и скрытые поля (включая CSRF-токен), затем отправляет **один**
POST с `os_username`/`os_password` на `/dologin.action` (либо серверный login.action).
Пароль отправляется только на точный host w.csl.by и стандартный login endpoint.
HTTP Basic не используется. Редирект/HTTP 200 не считается успешным входом:
обязательна проверка `/rest/api/user/current`, отклоняющая anonymous.

Стандартная форма Confluence поддерживается; внешний SSO, CAPTCHA и 2FA не
обходятся. Если форма/политика сервера отличается, показывается ошибка, а не сайт
внутри приложения. При CAPTCHA может потребоваться разблокировка администратором:
прохождение проверки в другом браузере не всегда разблокирует новую сессию.
Повторные попытки с паролем автоматически не выполняются, чтобы не блокировать аккаунт.

Если Confluence установлен в подпапке, в параметрах укажите, например,
`https://w.csl.by/confluence`. Не добавляйте `/rest/api` — это делает клиент.

## Как пользоваться

1. Установить APK и открыть **CSL Wiki Native**.
2. Нажать **«Войти в Confluence»** и ввести логин и пароль в нативные поля.
3. Нажать **«Войти»** — после проверки откроются пространства.
4. Открыть статью и нажать **«Сохранить»**. Текст доступен в разделе «Сохранённое»
   без интернета. Картинки и вложения требуют сеть.
5. При проблемах: **⋯ → Скопировать диагностику**. В ней нет паролей/cookies.

Новый пакет: `by.csl.wiki.nativeclient`; название **CSL Wiki Native** отличает его
от старого `by.csl.wiki` со страницей входа. Устанавливается рядом, прежние данные
не удаляются, но и не импортируются. Не нужно удалять старое приложение.

## Возможности и ограничения

- Пространства, страницы и CQL-поиск с постраничной загрузкой.
- История чтения и SQLite-кэш: 100 последних несохранённых статей, явно сохранённые
  не удаляются автоочисткой. Удаление из сохранённых не стирает историю; для полного
  удаления используйте очистку кэша или выход.
- Нативные обычные таблицы, списки, код, текст с форматированием. Сложные макросы,
  встроенные приложения, объединения ячеек и полная верстка сайта не воспроизводятся.
- Изображения-вложения того же сервера: первые четыре загружаются автоматически,
  всего до 12 на статью; 6 МБ максимум, декодирование с уменьшением до 1024 px.
  Не более 400 текстовых блоков, таблицы до 100 строк/12 столбцов.
- Локальный поиск до 100 совпадений. Пространства требуют сеть, офлайн-кэш — не
  зеркало всего Confluence.
- Очистка сессии, смена аккаунта или адреса удаляет локальные статьи.
- Сохранённые статьи приватны для приложения, но SQLite дополнительно не шифруется.
  Используйте блокировку устройства. Android backup выключен.
- Шифруется сессия, а не пароль: пароль остаётся в памяти лишь на время обработки
  входа и отправляется по HTTPS. Собственный ключ AES не хранится рядом с данными.
- Точный HTTPS host w.csl.by, проверка TLS не отключается. Для корпоративного CA
  разрешено системное/пользовательское хранилище доверия только на w.csl.by.
- Возможны требования корпоративного DNS/VPN и прав на REST API.

## Сборка и проверки

JDK 17 + Android SDK 35:

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest   # при подключённом Android/эмуляторе
```

GitHub Actions собирает APK, запускает JVM-тесты, Android Lint и тесты на эмуляторе
Android 10. Проверяются отсутствие WebView в форме и читателе, нативные поля,
пустой ввод без обращения к сети, офлайн-SQLite и реальное Android Keystore
шифрование сессии. В артефакте — APK, SHA-256 и скриншоты; статьи на тестовых
скриншотах — явно обозначенные тестовые фикстуры, не данные пользователя.

Форма/CSRF/URL-политики и нативная модель статьи покрываются JVM-тестами.
Тесты не подтверждают реальный вход на w.csl.by: доступ к хосту из среды
разработки запрещён. Вход на живом сервере проверяется на устройстве пользователя.

APK debug предназначен для тестирования. CI кэширует debug-keystore между новыми
нативными сборками, чтобы по возможности сохранять подпись при обновлениях;
сброс/утрата кэша меняет подпись. Для production нужен собственный стабильный
keystore через Secrets, а не debug key. Ключи/пароли подписи не коммитятся в Git.
